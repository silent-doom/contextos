## Submission gates

- [ ] Team eligibility verified in portal
- [ ] Live Gemini integration verified (offline mode does not qualify)
- [ ] Durable Google Cloud deployment accessible to judges
- [ ] Public GitHub repo (user deferred setup)
- [ ] Prescribed pitch PDF ≤5 MB
- [ ] Public video duration verified against active form
- [ ] Description ≤1,024 characters describes actual cloud services used
- [ ] Final rules, availability, source links and claims checked

Never present estimated context reduction as measured total token/cost savings. Collect live usage and task-quality evidence before making impact claims.
